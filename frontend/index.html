如何使用

输入出发地、目的地和日期区间，点击「搜索最低价」，即可查看该时间段内每天的价格热力图和最便宜的往返组合。

未配置 API 密钥时使用内置演示数据；接入 Amadeus 免费密钥后可查询真实价格（见 README）。
